# 设置窗口按需创建与内存验证

## 产品行为

- 正常启动显示设置窗口。标题栏关闭或 Ctrl+W 释放主窗口与 WebView，托盘和 Rust 平台层继续运行。
- 托盘显示、二次启动和遥控器“打开无线麦”共享创建/显示入口；释放中的显示请求延后到销毁完成，不创建重复窗口。
- 仅显式退出才清理平台资源；最后一个设置窗口销毁不能触发后台退出。
- 页面按需加载；状态轮询仅在文档可见时运行，单次请求未完成不启动下一轮。
- 未保存的按键配置只保留为本地草稿，不自动应用；权威配置发生变化时丢弃过期草稿。
- 主窗口销毁不依赖 Vue 卸载钩子：Rust 主线程撤销快捷键录入、恢复输入法让位和映射执行。BLE/语音会话不随窗口关闭停止。

## 自动化

- `pnpm test`：可见性暂停/恢复、慢请求不重叠、卸载中请求结束不重启轮询、草稿恢复及过期/损坏草稿处理。
- `pnpm build`：验证页面独立产出 chunk。
- `cargo fmt --all -- --check`、`cargo test --workspace`、`cargo check --workspace`。
- `cargo check -p sayall-windows-app --features runtime-simulation`。

## 本机验证方法

1. 记录已安装 release 的版本、PID 和关闭到托盘后的五次内存采样。
2. 请求原版正常退出，不强杀 BLE 实例。运行本地 Release 测试版，使用相同用户配置。
3. 确认页面真实渲染且 IPC 读回成功；切换四个页面。
4. 分别通过标题栏关闭路径和 Ctrl+W 释放窗口，确认主 PID 仍活着、应用关联 WebView2 进程退出。
5. 二次启动重建页面，确认 PID 不变、页面和 IPC 恢复；反复关闭/打开，确认不累积 WebView2 进程。
6. 关闭后的五次采样统计工作集和私有提交量；前者允许共享页面重复计算，后者不是物理内存。
7. 正常退出测试版后恢复原安装版，保留独立本地测试产物。

临时探针、CDP 截图及详细采样保存在仓库外，不作为生产依赖。

## 2026-10-10 本机结果

- 原安装版 0.8.6 与本地测试版均采用同一用户配置；测量只统计主进程及其按键宿主/WebView2 子进程，不含独立增强助手。
- 原版标题栏关闭到托盘后，五次样本平均工作集：Rust 宿主 23.75 MiB、WebView2 144.48 MiB，合计 168.23 MiB；私有提交合计 281.91 MiB。
- 测试版 Ctrl+W 关闭后，五次样本平均工作集 65.26 MiB、私有提交 14.24 MiB；WebView2 子进程数量为 0。
- 二次启动后主 PID 不变，真实页面与 IPC 恢复；连接页读回 RC001 已连接、语音与 CABLE 设备就绪。随后通过标题栏关闭，末次样本工作集 71.03 MiB、私有提交 15.79 MiB，WebView2 数量仍为 0。
- 使用 computer-use 实际切换按键/连接/权限/设置四个页面并保存本地截图；确认懒加载页面正确显示。按键页切走时有资源清理日志；正常重建未上报崩溃重载恢复。
- `pnpm test`：297 passed / 11 skipped；`pnpm build` passed；Rust 工作区：474 passed / 14 ignored；workspace check、runtime-simulation check 与格式检查 passed。跳过的测试不计入通过。
- 正式资源测试构建命令：`cargo build --release -p sayall-windows-app --features tauri/custom-protocol -j 1`。初次遗漏该特性的 Cargo 构建只创建窗口、未加载正式前端，已纠正，不计入界面验证。
- 工作集受共享页、缓存和系统分页影响；上述为同状态短时样本，不能承诺每次启动固定占用，也不能证明长期无泄漏。

## 必须由真实设备补足的边界

RC001/RC003 各自覆盖关闭界面后语音输入、冷态首按、连续会话、断连与睡眠恢复；实际点击托盘；退出中迟到回调。构建、IPC、连接状态及内存测量不能替代上述硬件验收。
